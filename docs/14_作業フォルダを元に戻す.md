# 作業フォルダを元に戻す（AI にファイルを壊されたとき）

AI に作業を任せていると、大事なファイルを書き換えられたり、消されたりすることがあります。
このパッケージの安全装置は、危ない操作を「実行する前」に止める仕組みです。作業フォルダの中でファイルを直したり消したりする普通の操作までは止めません。

そのため、AI を起動する直前に作業フォルダの「控え」を自動で取り、あとからボタン 1 つでその時点へ戻せるようにしてあります。
控えは作業フォルダの中の隠しフォルダに入っていて、AI からは読むことも消すこともできない場所です。

## 1. いつ控えを取るのか

スタートフォルダの「4_AIを起動する」か「6_長時間おまかせモードで起動」から AI を起動すると、AI が動き出す直前に控えを取ります。
画面に「作業フォルダの控えを取りました（120 ファイル・0.3 秒）」のような 1 行が出ていれば、控えは取れています。
前回の控えから何も変わっていないときは、同じ控えを増やしません。

控えは最大 30 回分を残し、それより古いものは自動で整理します。
同じ中身のファイルは 1 回しか保存しないので、控えを何回取っても、増える容量は変わったファイルの分だけで済みます。

次の使い方では控えが自動では取られないので、気をつけてください。

- Codex デスクトップアプリや AGI Cockpit から AI を使うとき
- ボタンを使わず、黒い画面で `claude` や `codex`、`codex-safe` などを直接打って起動したとき

このようなときは、作業を頼む前に「10_作業フォルダを元に戻す」を開き、`s` を入力して Enter を押してください。その時点の控えを手で取れます。

## 2. 控えの置き場所

控えは作業フォルダ（my-ai-workspace）の中の `.ai-safety/snapshots/` に入っています。
この場所は安全ポリシーで AI の読み書きが止められているので、AI が控えを消したり、書き換えたり、中をのぞいたりすることはできません。

中身のファイルは数字と英字の並んだ名前で保存されていて、フォルダを開いても元のファイル名はわかりません。
中身を直接いじると戻せなくなるおそれがあります。戻すときは必ず「10_作業フォルダを元に戻す」のボタンを使ってください。

## 3. 元に戻す手順

1. スタートフォルダの「10_作業フォルダを元に戻す」をダブルクリックします（Mac は `.command`、Windows は `.bat`）。
2. 控えの一覧が新しい順に出るので、日時と「Claude Code の起動前」のような説明を見て、戻したい時点の番号を入れて Enter を押してください。
3. 戻すと何が変わるかが表示されます。「控えの中身に戻すファイル」と「脇へ片付けるファイル」の一覧を確かめましょう。
4. よければ `y` を入力して Enter を押すと、元に戻ります。やめるときは何も入れずに Enter を押すだけで、何も変わりません。
5. 終わると、戻したファイルの数と、片付けたファイルの置き場所が画面に出るので、確認してください。

戻している途中は、画面を閉じないでください。
どの控えを選べばよいか迷ったときは、AI に作業を頼む前の時点を探します。Claude Code に頼んだ作業を取り消したいなら、その日時の「Claude Code の起動前」が目安です。

## 4. 片付けられたファイルと、「元に戻す」の取り消し

控えを取ったあとで新しくできたファイルは、消さずに `.ai-safety/snapshots/set-aside/（日時）/` へ移します。
元の場所と同じフォルダ構成のまま入っているため、必要なファイルはそこから作業フォルダへコピーして戻せます。
Mac の Finder は名前が「.」で始まるフォルダを表示しないので、戻し終わったあとに「片付けたファイルの場所を開きますか？」と聞かれたら `y` を押してください。
Finder で自分で探すときは、Command と Shift と「.」（ピリオド）を同時に押すと隠しフォルダが見えるようになります。

片付けたファイルは自動では消えません。いらなくなったら、ご自身で削除してください。

元に戻す直前の状態も、「元に戻す直前」という名前の控えとして自動で取ってあります。
戻す時点を間違えたときは、もう一度「10_作業フォルダを元に戻す」を押し、一覧から「元に戻す直前」を選んでください。
元に戻す前の状態へ、そのまま戻せます。

## 5. 控えに入らないもの・元に戻せないもの

控えの対象は、作業フォルダの中のファイルに限られます。
次のものは控えに入らないため、このボタンでは戻せません。

- 作業フォルダ（my-ai-workspace）の外にあるファイル
- 50 MB を超える大きなファイル（動画など）。元に戻すときも、そのまま残して動かしも消しもしません
- プログラムの部品やキャッシュのフォルダ（`.git`、`node_modules`、`.venv`、`venv`、`__pycache__`、`.next`、`.nuxt`、`.cache`、`.turbo`）の中身と、`.DS_Store`・`Thumbs.db`
- 安全パッケージが管理している場所（`.ai-safety`、`.claude`、`.codex`、`.gemini`、スタートフォルダ、パッケージが配った説明書）。こちらは「1_安全パッケージを最新版にする」で入れ直せます。docs フォルダに自分で置いたメモは控えに入ります
- ショートカット（シンボリックリンク）。リンクそのものも、リンク先のファイルも控えに入れません
- ほかのアプリが開いていて読めなかったファイル（Windows で Excel が使用中のファイルなど）
- 空のフォルダ。控えるのはファイルなので、中身のないフォルダは元に戻しても作られないことがあります

ファイルの外で起きたことも、元には戻せません。

- 送ってしまったメールやチャットのメッセージ
- GitHub などへの push、Web サービスへのアップロードや投稿
- 外部サービスの設定変更、課金、データベースの中身の書き換え
- 作業フォルダの外へのソフトのインストールや、パソコンの設定の変更

このボタンは「壊されたあとに戻す」ための最後の手段です。外へ送る操作や取り返しのつかない操作は、これまでどおり AI に任せきりにしないでください。

## 6. 困ったとき

起動のときに「元に戻す用の控えを取れませんでした（理由）」と出ても、AI はそのまま起動します。
カッコの中に「空き容量が足りない」と出た場合は、いらないファイルを消して空き容量を増やしてください。パソコンの空き容量が 1 GB を切りそうなときは、控えを取らない決まりにしています。
「ほかの画面で控えの作業をしている最中です」と出たときは、別の画面で AI を起動している途中かもしれません。少し待ってから起動し直せば控えを取れるでしょう。

作業フォルダに大きなファイルやたくさんのファイルがあると、初回の控えには時間がかかります。2 回目からは変わったファイルだけを保存するため、ずっと速くなります。
控えに 2 分以上かかったときは途中でやめて AI の起動を続け、次の起動のときに続きから進めるので、待ち続ける必要はありません。

OneDrive や iCloud に「クラウドだけに置いてある」ファイルがあると、控えを取るときにダウンロードが起きることがあります。作業フォルダはパソコンの中に実体を置いておくのがおすすめです。

「元に戻す」のあとに「うまくいかなかったファイルがあります」と出た場合は、そのファイルを開いているアプリ（Excel やエディタなど）を閉じてから、もう一度同じ控えを選んでください。

## 7. 詳しい人向けのメモ

- 実体は `.ai-safety/hooks/common/workspace-snapshot.js` です。git は使っていません（Node.js だけで動きます）
- 保存形式は、中身の SHA-256 を名前にしたファイル（`objects/`）と、時点ごとの一覧（`manifests/<id>.json`）です。書き戻す前に中身の SHA-256 を照合し、一覧のパスが作業フォルダの外や `.ai-safety` の中を指していたら、その控えは使いません
- コマンドで使うときは `node .ai-safety/hooks/common/workspace-snapshot.js take|list|diff|restore|prune --workspace <作業フォルダ>` です（`restore` には `--id <番号>` と `--yes` を付け、試すだけなら `--dry-run` を付けます）
- 環境変数で調整できます。`AI_SAFE_SNAPSHOT=off`（起動時の控えを止める）、`AI_SAFE_SNAPSHOT_MAX_MB`（大きさの上限、既定 50）、`AI_SAFE_SNAPSHOT_KEEP`（残す数、既定 30）、`AI_SAFE_SNAPSHOT_TIMEOUT_SEC`（起動時の控えにかける時間の上限、既定 120 秒）
