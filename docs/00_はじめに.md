## なぜこのパッケージが必要か

AI エージェントは、これまでの AI チャットとは違って、

- あなたのパソコンのファイルを読む
- あなたのパソコンでコマンドを実行する
- 外部の Web サイトを見に行く

ということを**自分の判断で**やります。便利な反面、間違った指示やプロンプトインジェクションで暴走すると、**機密ファイルの流出**や**ファイルの破壊**につながります。

このパッケージは、AI が「やってはいけないこと」をしようとした時に、**実際に止める**装置です。アクセル全開で AI を使えるのは、ちゃんとブレーキとガードレールがあるからです。

## このパッケージの位置づけ

| 項目 | 内容 |
|---|---|
| 想定利用者 | 個人〜小規模チーム |
| 想定環境 | 学校 PC（共用 Windows）/ 自宅 Windows / 自宅 Mac |
| 想定期間 | 3 ヶ月以上の継続運用 |
| 想定ツール | Codex CLI（主）、Claude Code、Gemini CLI、Cursor 拡張 |
| 守る範囲 | CLI 経由のファイル操作・コマンド実行・通信 |
| 守れない範囲 | ブラウザで直接 AI を使う場合 / 利用者が手動で hook を消した場合 |

## 動線

1. **インストール**：OS 別の手順書（`01_` / `02_` / `03_`）に従ってインストール
2. **使う**：`safe-workspace` フォルダの中で AI を起動するだけ
3. **動作確認**：`doctor` スクリプトを走らせて 10 種の攻撃が止まることを確認
4. **困ったら**：`docs/99_known_issues.md` または講師へ
