# はじめに

> ## 🚀 今すぐインストールしたい方
>
> **→ 同梱の `スタート.html` をブラウザで開いてください**（いちばん親切な案内です）。
>
> パッケージのフォルダにある `1_安全パッケージを準備-Windows.bat` (Windows) または `1_安全パッケージを準備-Mac.command` (Mac) を**ダブルクリックするだけ**で完了します。
>
> 手打ちでコマンドを打つ必要はありません。文字だけの手順がよい方は [00_クイックスタート.md](00_クイックスタート.md) へ。

このパッケージは、AI エージェント（Codex CLI、Claude Code、OpenCode、Gemini CLI）を**本物のプロジェクトで安心して使う**ための安全装置です。バージョン **v1.17.1**。

> **この安全装置ぜんぶの呼び名が「Bouncer（用心棒）」です。** 特定のファイル 1 本の名前ではありません。中身は役割で 3 人に分かれています。
>
> - **止める人** … 実行される前に危ないものを止めます（実行前チェック・権限リスト）
> - **見せる人** … 何が起きたかを全部見せます（見守りモニター・判断カード・記録・AI コーチ）
> - **伏せる人** … 外へ出ていく文章から秘密を伏せます（送信検査・マスキング）
>
> くわしくは [91_やさしい仕組み解説.md](91_やさしい仕組み解説.md) を読んでください。

## なぜこのパッケージが必要か

AI エージェントは、これまでの AI チャットとは違って、

- あなたのパソコンのファイルを読む
- あなたのパソコンでコマンドを実行する
- 外部の Web サイトを見に行く

ということを**自分の判断で**やります。便利な反面、間違った指示やプロンプトインジェクションで暴走すると、**機密ファイルの流出**や**ファイルの破壊**につながります。

このパッケージは、AI が「やってはいけないこと」をしようとした時に、**実際に止める**装置です。アクセル全開で AI を使えるのは、ちゃんとブレーキとガードレールがあるからです。

## 課金状況別・どの AI を使うか（この表が正本です）

「どの AI を入れればいいの？」は、あなたの課金状況で決まります。

| あなたの課金状況 | 使う AI | どこから起動するか | 守られ方 |
|---|---|---|---|
| 無課金 | AntiGravity（agy・無料） | スタート「4_セーフAntiGravityを起動」 | 見張り + 記録係（agy 自身の Secure Mode を併用） |
| 無課金（Claude 相当が欲しい） | OpenCode + DeepSeek（少額チャージ） | スタート「1_AIをまとめて起動」→ OpenCode を選ぶ | **壁は無し**。見張り（権限リスト）+ 記録係 + DeepSeek 向けの送信検査 |
| 無課金（Codex を使いたい） | **Codex デスクトップアプリ**（無料プランでも使えます） | アプリを起動 ＋ スタート「（上級）5_このPC全体に最低限の安全設定を入れる」を 1 度押しておく | 壁（アプリ自身）+ 見張り + 記録係（上級 5 を押した場合。→ [20_卒業後ガイド.md](20_卒業後ガイド.md) 4-4） |
| ChatGPT 課金 | Codex CLI | スタート「1_AIをまとめて起動」→ Codex、または「2_セーフCodexを起動」 | 壁 + 見張り + 記録係（Windows でも壁あり） |
| Claude 課金 | Claude Code | スタート「3_セーフClaudeを起動」、または AGI Cockpit（作業フォルダ = my-ai-workspace） | Mac は壁 + 見張り + 記録係 / **Windows は壁なし**（見張り + 記録係） |
| 複数課金 | 複数エージェント | AGI Cockpit を司令塔に Claude を使い、Codex はスタート「2_」ボタンから | [11_AGI-Cockpitで使う.md](11_AGI-Cockpitで使う.md) 参照 |

補足:

- **ブラウザの ChatGPT（無料枠）** はそのまま使えますが、このパッケージの守備範囲外です（[90_守れる-守れない.md](90_守れる-守れない.md)）。
- **Codex のデスクトップアプリは、ChatGPT の無料プランでも使えます**（実機で確認しました）。**Codex CLI のほうがどのプランで使えるかは変わることがあるので、必ず公式で確認してください**（https://openai.com/chatgpt/pricing/ ）。金額や条件はこのページには書きません。
- **Claude Code / Claude Desktop は無料プランでは使えません**。無課金で Claude 相当が欲しい場合は OpenCode + DeepSeek 経路を使ってください。

## 守られ方の言葉づかい（「壁」「見張り」「記録係」）

このパッケージの守り方は AI ツールごとに強さが違います。ごまかさずに書きます。以下の 3 つの言葉で統一して説明します。

| 言葉 | 正式には | 何をするか | どの AI にあるか |
|---|---|---|---|
| **壁** | OS サンドボックス（Mac は Seatbelt、Linux / WSL2 は bubblewrap、Windows は Codex 専用の低権限ユーザーとファイアウォール） | パソコン本体（OS）が力ずくで止める。AI が何を考えても越えられない | Codex CLI（Mac / Linux / WSL2 / Windows）、Claude Code（Mac / Linux / WSL2） |
| **見張り** | 実行前チェック（このパッケージの hook、Claude Code の権限リスト、OpenCode の権限リスト） | AI が何かする直前に、人が決めたリストと照らし合わせて止める | すべての経路。**Windows の Claude Code はこれだけ**で守る |
| **記録係** | 監査ログと見守りモニター | 止めはしないが、何が起きたかを全部記録する | すべての経路（[07_AIの動きをモニターする.md](07_AIの動きをモニターする.md)） |

**とくに大事な 2 つの正直な話**

1. **壁が止めるのは「書き込み」と「外への通信」だけです。「読み取り」は設計上止まりません。** 壁が効いている状態でも、AI はパソコン中のファイルを読めます（実測で確認済み）。パスワードや鍵の入ったファイルを守っているのは、壁ではなく**見張り**のほうです。だから `.ai-safety` フォルダ（見張りの本体）を消したり書き換えたりしないでください。
2. **OpenCode には壁がありません。** 作った人たち自身が公式の文書に「これはセキュリティの隔離ではない」と書いています。このパッケージは見張りを厚くしていますが、見張りは「想定していないやり方」には気づけません。OpenCode は、このパッケージが用意した用途（DeepSeek を使う）以外には使わないでください。

3 つをまとめて「サンドボックスで守られています」とは言いません。事実と違うからです。
