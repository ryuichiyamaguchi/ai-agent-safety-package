## なぜこのパッケージが必要か

AI エージェントは、これまでの AI チャットとは違って、

- あなたのパソコンのファイルを読む
- あなたのパソコンでコマンドを実行する
- 外部の Web サイトを見に行く

ということを**自分の判断で**やります。便利な反面、間違った指示やプロンプトインジェクションで暴走すると、**機密ファイルの流出**や**ファイルの破壊**につながります。

このパッケージは、AI が「やってはいけないこと」をしようとした時に、**実際に止める**装置です。アクセル全開で AI を使えるのは、ちゃんとブレーキとガードレールがあるからです。

## このパッケージの位置づけ

| 項目 | 内容 |
|---|---|
| 想定利用者 | 個人〜小規模チーム |
| 想定環境 | 学校 PC（共用 Windows）/ 自宅 Windows / 自宅 Mac |
| 想定期間 | 3 ヶ月以上の継続運用 |
| 想定ツール | 下の「課金状況別・どの AI を使うか」を参照 |
| 守る範囲 | CLI 経由のファイル操作・コマンド実行・通信 |
| 守れない範囲 | ブラウザで直接 AI を使う場合 / 利用者が手動で hook を消した場合 |

## 課金状況別・どの AI を使うか（この表が正本です）

「どの AI を入れればいいの？」は、あなたの課金状況で決まります。

| あなたの課金状況 | 使う AI | どこから起動するか | 守られ方 |
|---|---|---|---|
| 無課金 | AntiGravity（agy・無料） | スタート「4_セーフAntiGravityを起動」 | hook + OS 隔離 |
| 無課金（Claude 相当が欲しい） | OpenCode + DeepSeek（少額チャージ） | スタート「1_AIをまとめて起動」→ OpenCode を選ぶ | 最大（送信検査 Gateway + curl/wget 拒否） |
| ChatGPT 課金 | Codex CLI | スタート「1_AIをまとめて起動」→ Codex、または「2_セーフCodexを起動」 | 4 層フル |
| Claude 課金 | Claude Code | スタート「3_セーフClaudeを起動」、または AGI Cockpit（作業フォルダ = my-ai-workspace） | 4 層フル（Cockpit 経由でも hook 有効・実測済み） |
| 複数課金 | 複数エージェント | AGI Cockpit を司令塔に Claude を使い、Codex はスタート「2_」ボタンから | [11_AGI-Cockpitで使う.md](11_AGI-Cockpitで使う.md) 参照 |

補足:

- **ブラウザの ChatGPT（無料枠）** はそのまま使えますが、このパッケージの守備範囲外です（[90_守れる-守れない.md](90_守れる-守れない.md)）。Codex CLI は ChatGPT 課金が前提です。
- **Claude Code / Claude Desktop は無料プランでは使えません**。無課金で Claude 相当が欲しい場合は OpenCode + DeepSeek 経路を使ってください。

## 動線

1. **インストール**：`スタート.html` または OS 別の手順書（`01_` / `02_` / `03_`）に従ってインストール
2. **使う**：作業フォルダ（my-ai-workspace）の「スタート」フォルダのボタンから AI を起動するだけ
3. **動作確認**：スタート「9_困ったとき診断」を押して攻撃ドリルが止まることを確認
4. **困ったら**：スタート「9_困ったとき診断」→ [99_known_issues.md](99_known_issues.md) →（在校中は）講師へ。卒業後の調べ方は [20_卒業後ガイド.md](20_卒業後ガイド.md)
