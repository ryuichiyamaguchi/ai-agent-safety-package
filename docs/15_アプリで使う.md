# アプリで使う — いちばんかんたんな入口

「スタート」フォルダのボタンを 1 つずつ押す代わりに、**アプリ 1 つ**で安全パッケージを使えます。AI の起動、見守りモニター、困ったときの診断、キーや金庫の設定まで、すべてアプリの画面から操作できます。

これから始める人は、まずアプリを入れてください。「スタート」フォルダのボタンもこれまでどおり使えます。どちらから操作しても、中で動いている安全装置は同じです。

## 1. アプリでできること

| 画面 | できること |
|---|---|
| **AIを起動する** | 使う AI をボタンで選んで起動します（無料 → 少額チャージ → 課金の順に並んでいます）。「じぶんに合うAIを選ぶ」ガイドもここから開けます |
| **見守りモニター** | AI がいま何をしようとしているかを、アプリの中に表示します。AI を起動すると自動で切り替わります |
| **困ったとき診断** | 安全装置がきちんと動いているかを調べ、「正常」か「問題 ○ 件」かを表示します |
| **使い方ガイド** | 説明書を開きます |
| **⚙ 設定** | 安全パッケージの更新、AI ツールの導入と更新、キーの登録と削除、金庫、秘密の伏せ字、PC 全体の安全設定、作業フォルダの変更 |

> **アプリは入口です。守っているのはアプリではありません。** 危険なコマンドを止める仕組みは、これまでどおり作業フォルダ（`my-ai-workspace`）の中の `.ai-safety` が受け持っています。アプリはそれを呼び出しているだけなので、アプリを閉じても、アプリを入れていなくても、守りは変わりません。キーや秘密の入力も、アプリではなく黒い画面（ターミナル / PowerShell）で行います。

## 2. 入手する

安全パッケージの公開ページ（GitHub の「Releases」）から、自分のパソコン用のファイルをダウンロードします。

- 公開ページ: <https://github.com/ryuichiyamaguchi/ai-agent-safety-package/releases/latest>
- **Mac**（M1 以降の Apple シリコン）: 名前に `mac-arm64` が入った `.zip`
- **Windows**（64 ビット）: 名前に `windows-x64-setup` が入った `.exe`

> Intel チップの Mac 用はありません。Intel Mac の人は「スタート」フォルダのボタンを使ってください。
>
> 同じページに `.sha256` という小さなファイルも置いてあります。ダウンロードしたファイルが途中で壊れたり、すり替えられたりしていないかを確かめるための「指紋」です。

## 3. はじめて開くとき（1 回だけ警告が出ます）

このアプリは、Apple や Microsoft の有料の「発行元の証明」を取っていません。そのため**はじめて開くときに一度だけ**、パソコンが「このアプリは確認できません」と止めます。次の手順で開いてください。**2 回目からは出ません。**

### Mac

1. ダウンロードした `.zip` をダブルクリックして展開し、出てきた **「AI安全パッケージ」** を「アプリケーション」フォルダへ移します
2. 「AI安全パッケージ」をダブルクリックします。「開けません」と出たら **「完了」** を押して閉じます
3. **システム設定 → プライバシーとセキュリティ** を開き、下のほうにある「"AI安全パッケージ" は…ブロックされました」の横の **「このまま開く」** を押します
4. もう一度確認が出たら **「開く」** を押します（パスワードや Touch ID を求められたら入力します）

### Windows

1. ダウンロードした `...windows-x64-setup.exe` をダブルクリックします
2. 青い画面で「Windows によって PC が保護されました」と出たら、**「詳細情報」** を押し、出てきた **「実行」** を押します
3. 案内に沿ってインストールします（管理者のパスワードは要りません。自分のユーザーだけに入ります）

> ⚠️ **この「警告を押して進む」操作は、このアプリのように、配布元がはっきりしていて自分で入手したファイルにだけ行ってください。** メールやチャットで届いたファイル、出どころの分からないファイルで同じ警告が出たら、開かずに削除するのが正解です。

## 4. 最初の画面

アプリを開くと、まず作業フォルダ（`書類` / `Documents` の中の `my-ai-workspace`）を自動で探します。

- **見つかったとき** — そのまま「AIを起動する」の画面になります
- **見つからないとき** — **「安全パッケージを入れる」** を押すと、公開ページから最新の安全パッケージを取ってきて、「指紋」（SHA-256）を照合してから入れます。黒い画面に **「✅ 更新が完了しました」** と出るまで待ってから（数分かかります）、**「入れ終わったので次へ」** を押します
- 別の場所に作業フォルダがある人は **「別のフォルダを選ぶ…」** から選びます

## 5. 更新

新しい版が出ると、「⚙ 設定」に印が付き、「AIを起動する」の画面にも案内が出ます。**「⚙ 設定 → 安全パッケージを最新版にする」** を押してください。

アプリそのものの新しい版は、2 の公開ページから入れ直します（作業フォルダの中身・キー・金庫はそのまま残ります）。

## 6. 困ったとき

- まず **「困ったとき診断」** を押し、「問題」と出た項目の案内に従ってください
- アプリが開かない・画面が真っ白なときは、「スタート」フォルダのボタン（**9_困ったとき診断** など）からも同じことができます
- それでも分からなければ [99_known_issues.md](99_known_issues.md) と [20_卒業後ガイド.md](20_卒業後ガイド.md) の「困ったときの調べ方」を見てください
