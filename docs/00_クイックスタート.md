# クイックスタート（ダブルクリックでインストール）

**これだけ読めば使えます。**

---

## Windows の方

1. ZIP ファイルをダウンロードして**展開（解凍）**する
2. 展開したフォルダの中の `scripts\windows\` を開く
3. **`install-one-click.bat` をダブルクリック**する

以上です。あとは画面の案内に従うだけでインストールが完了します。

### 「Windows によって PC が保護されました」が出たら

1. 「**詳細情報**」をクリック
2. 「**実行**」をクリック

これだけで進めます。このファイルはパッケージに付属の正規ファイルです。

---

## Mac の方

1. ZIP ファイルをダウンロードして**展開（解凍）**する
2. 展開したフォルダの中の `scripts/macos/` を開く
3. **`install-one-click.command` を右クリック → 「開く」→「開く」**する

以上です。ターミナルが開いて自動的にインストールが進みます。

### 「ゴミ箱に入れる / 完了」しか出てこない場合（最新 macOS）

macOS Sonoma 14.4 以降と Sequoia 15 では、Apple のセキュリティが強化されて、上の「右クリック → 開く」だけでは開けないことがあります。次のいずれかで進めます。

**方法 A：システム設定から許可する（マウスだけで完結）**

1. ダイアログで「**完了**」を押す（**「ゴミ箱に入れる」は絶対に押さない**）
2. 画面左上の Apple マーク → **「システム設定」**を開く
3. 左のメニューから **「プライバシーとセキュリティ」**
4. 画面を一番下までスクロール → **「"install-one-click.command" は開発元を確認できないためブロックされました」** の横にある **「このまま開く」** ボタンを押す
5. Mac のパスワード（または Touch ID）を入力
6. 改めて Finder で `install-one-click.command` をダブルクリック → 今度は「開きますか？」と聞かれるので **「開く」**

**方法 B：ターミナルで 1 行（早い）**

「アプリケーション → ユーティリティ → ターミナル」を開き、次の 1 行をコピペして Enter:

```bash
xattr -d com.apple.quarantine ~/Downloads/ai-agent-safety-package-v1/scripts/macos/install-one-click.command
```

その後、Finder でダブルクリックすれば普通に開きます。

> 上の `~/Downloads/...` の部分は、ZIP を展開した実際の場所に合わせてください（デスクトップに置いたなら `~/Desktop/...`）。

## インストール後、毎回これで起動してください

### Windows

```powershell
cd $env:USERPROFILE\Documents\my-ai-workspace
powershell -File .ai-safety\hooks\windows\launch-codex-safe.ps1
```

### Mac

```bash
cd ~/Documents/my-ai-workspace
bash .ai-safety/hooks/macos/launch-codex-safe.sh
```

> **重要**: 素の `codex` コマンドを直接打たないでください。`launch-codex-safe` を使わない場合、このパッケージの launcher 経由の保護は効きません。
