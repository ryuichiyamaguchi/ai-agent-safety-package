# クイックスタート（ダブルクリックでインストール）

**これだけ読めば使えます。**

---

## Windows の方

1. ZIP ファイルをダウンロードして**展開（解凍）**する
2. 展開したフォルダを開く（`スタート.html` がある場所）
3. **`1_安全パッケージを準備-Windows.bat` をダブルクリック**する

以上です。あとは画面の案内に従うだけでインストールが完了します。

### `.bat` が止められる / PowerShell に貼ってしまった場合

`.bat` の中身を PowerShell に貼り付けないでください。`@echo off` や `%~dp0` は PowerShell では動きません。

代わりに、展開したフォルダ（`スタート.html` がある場所）を開き、エクスプローラーのアドレスバーに `powershell` と入力して Enter。開いた PowerShell に次の 1 行を貼ってください。

```powershell
if (Test-Path ".\scripts\windows\install.ps1") { Get-ChildItem -LiteralPath . -Recurse -ErrorAction SilentlyContinue | Unblock-File -ErrorAction SilentlyContinue; powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\windows\install.ps1" -Workspace "$env:USERPROFILE\Documents\my-ai-workspace" } else { Write-Host "スタート.html があるフォルダで PowerShell を開き直してください" }
```

### 「Windows によって PC が保護されました」が出たら

1. 「**詳細情報**」をクリック
2. 「**実行**」をクリック

これだけで進めます。このファイルはパッケージに付属の正規ファイルです。

## Mac の方

1. ZIP ファイルをダウンロードして**展開（解凍）**する
2. 展開したフォルダを開く（`スタート.html` がある場所）
3. **`1_安全パッケージを準備-Mac.command` を右クリック → 「開く」→「開く」**する

以上です。ターミナルが開いて自動的にインストールが進みます。

### 「ゴミ箱に入れる / 完了」しか出てこない場合（最新 macOS）

macOS Sonoma 14.4 以降と Sequoia 15 では、Apple のセキュリティが強化されて、上の「右クリック → 開く」だけでは開けないことがあります。次のいずれかで進めます。

**方法 A：システム設定から許可する（マウスだけで完結）**

1. ダイアログで「**完了**」を押す（**「ゴミ箱に入れる」は絶対に押さない**）
2. 画面左上の Apple マーク → **「システム設定」**を開く
3. 左のメニューから **「プライバシーとセキュリティ」**
4. 画面を一番下までスクロール → **「"1_安全パッケージを準備-Mac.command" は開発元を確認できないためブロックされました」** の横にある **「このまま開く」** ボタンを押す
5. Mac のパスワード（または Touch ID）を入力
6. 改めて Finder で `1_安全パッケージを準備-Mac.command` をダブルクリック → 今度は「開きますか？」と聞かれるので **「開く」**

**方法 B：ターミナルで 1 行（早い）**

「アプリケーション → ユーティリティ → ターミナル」を開き、次の 1 行をコピペして Enter:

```bash
xattr -d "com.apple.quarantine" ~/Downloads/ai-agent-safety-package-v1/1_安全パッケージを準備-Mac.command
```

その後、Finder でダブルクリックすれば普通に開きます。

> 上の `~/Downloads/...` の部分は、ZIP を展開した実際の場所に合わせてください（デスクトップに置いたなら `~/Desktop/...`）。

## インストール後、毎回これで起動してください

### Windows

```powershell
cd $env:USERPROFILE\Documents\my-ai-workspace
powershell -File .ai-safety\hooks\windows\launch-integrated.ps1 -Workspace . -Agent codex -Profile standard
```

または、作業フォルダの中の `スタート\1_AIをまとめて起動.bat` を開きます。

### Mac

```bash
cd ~/Documents/my-ai-workspace
bash .ai-safety/hooks/macos/launch-integrated.sh "$(pwd)" codex standard
```

または、作業フォルダの中の `スタート/1_AIをまとめて起動.command` を開きます。従来名の `2_セーフCodexを起動.command` と `3_セーフClaudeを起動.command` も、Mac版では統合ランチャーの標準モードへ接続されています。

OpenCode + DeepSeekと、Claude Codeの操作感でDeepSeekを使う `d-claude` も同じ統合メニューから選べます。どちらも送信検査（伏せる人）と見守りモニター（見せる人）を同時に起動します。通常はOpenCodeのWeb検索OFFを選んでください。詳しくは [10_OpenCode_DeepSeekを安全に使う.md](10_OpenCode_DeepSeekを安全に使う.md) を参照してください。

どの AI を使えばよいか迷ったら、[00_はじめに.md](00_はじめに.md) の「課金状況別・どの AI を使うか」の表を見てください。

> **重要**: 素の `codex` / `claude` / `d-claude` コマンドを直接打たないでください。`launch-integrated` を使わない場合、見守り UI を含む統合版の保護はそろいません。
>
> **これは「一切効かない」という意味ではありません。** スタートの **「（上級）5_このPC全体に最低限の安全設定を入れる」** を押してあれば、素起動でも**見張り（危険コマンドの禁止・秘密ファイルの保護）と記録**は効きます。Codex は壁も効きます。ただし **Claude の壁は作業フォルダの中でしか効かず**、CLAUDE.md・スキル・説明書もありません。くわしい対比表は [20_卒業後ガイド.md](20_卒業後ガイド.md) の 9-3 にあります。
>
> 長いコマンドの代わりに、短い呼び名 **`claude-safe` / `codex-safe` / `oc-safe` / `agy-safe`** を使ってください（導入時に `~/.ai-safety/bin/` に置かれ、PATH も通ります）。**Zed / Cursor / tmux / Windows Terminal など、どのターミナルからでも同じです。** ターミナルを開き直しても見つからないときは、上の長いコマンドを使ってください。
