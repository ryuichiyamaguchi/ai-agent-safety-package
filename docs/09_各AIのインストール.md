# 各 AI（CLI）のインストール

このパッケージの launcher は、**各 AI の CLI が既に入っている**ことを前提に動きます。
この 1 枚で、Codex CLI / Claude Code / OpenCode / Antigravity CLI を**自分の PC に入れる手順**をまとめます。

> **どれを入れればいい？** → [00_はじめに.md](00_はじめに.md) の「課金状況別・どの AI を使うか」の表で決めてください。全部入れる必要はありません。

> **初回はこのページ、2 回目以降はボタンで更新**：ここに書いてあるのは「最初に入れる」手順です。すでに入れたツールを新しくしたいときは、スタートフォルダの **「8_AIツールを最新版に更新」** をダブルクリックするだけです（入っていないツールは自動でスキップされます）。更新の習慣は [20_卒業後ガイド.md](20_卒業後ガイド.md) の「更新はこれからも受け取れます」を見てください。

> ## ⚠ 起動は必ず `launch-*-safe` 経由で
>
> CLI を入れても、**素の `codex` / `claude` / `opencode` / `gemini` / `agy` を直接打たないでください**。
> このパッケージの安全装置（hook 層・環境変数フィルタ・サンドボックス強制）は、`launch-*-safe` を**経由した時だけ**効きます。
> 各 CLI の起動方法は、このページの一番下「[インストール後の起動方法](#インストール後の起動方法必ずこれで起動)」を必ず読んでください。

## まず前提：Node.js（LTS 版）を入れる

Codex CLI・Claude Code・Gemini CLI は **Node.js 経由**（`npm` コマンド）で入れます。先に Node.js を入れてください。
（Antigravity CLI だけは Node.js 不要です。）

### Windows

[nodejs.org](https://nodejs.org/) を開いて **LTS 版の MSI** をダウンロード → ダブルクリックでインストール。

入ったか確認（PowerShell で）：

```powershell
node --version
npm --version
```

> **Windows の方は先に「最初の儀式」を**：`npm` コマンド（実体は `npm.ps1`）が動くように、`npm install` する前に必ず以下を 1 回だけ実行してください（詳細は [02_自宅Windowsで使う.md](02_自宅Windowsで使う.md) の「ステップ 0」）。
>
> ```powershell
> Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
> ```

### Mac

[nodejs.org](https://nodejs.org/) から **LTS 版のインストーラ（.pkg）** をダウンロード → ダブルクリックでインストール。

入ったか確認（ターミナルで）：

```bash
node --version
npm --version
```

## 1. Codex CLI

OpenAI の Codex CLI です。

### Windows

```powershell
npm install -g @openai/codex
codex --version
codex login
```

### Mac

```bash
npm install -g @openai/codex
codex --version
codex login
```

> **Apple Silicon Mac（M1/M2/M3…）で `codex --version` が動かない場合**は、Rosetta 経由で入れ直します：
>
> ```bash
> arch -x86_64 npm install -g @openai/codex
> ```

→ 起動は `launch-codex-safe` 経由で（[下記](#インストール後の起動方法必ずこれで起動)）。

## 2. Claude Code

Anthropic の Claude Code です。

### Windows

> **先に Git for Windows を入れておくことを推奨**します（Claude Code の一部機能で必要になる場合があります。バージョンによっては無くても動くことがあります）。
> [https://gitforwindows.org/](https://gitforwindows.org/) から入れて、`git --version` でバージョンが表示されれば OK です。

```powershell
npm install -g @anthropic-ai/claude-code@2.1.201
claude --version
```

### Mac

```bash
npm install -g @anthropic-ai/claude-code@2.1.201
claude --version
```

> うまく入らない場合は `npm install -g @anthropic-ai/claude-code@2.1.201 --force` を試してください。

→ 起動は `launch-claude-safe` 経由で（[下記](#インストール後の起動方法必ずこれで起動)）。

## 3.5 OpenCode（DeepSeek標準経路）

公式のNode.js版をMac / Windows共通で導入できます。

```bash
npm install -g opencode-ai
opencode --version
```

統合版は **1.14.24以上**を要求します。DeepSeekの実キーはOpenCodeへ登録せず、統合ランチャーの送信検査Gatewayだけが読み取ります。詳しくは [10_OpenCode_DeepSeekを安全に使う.md](10_OpenCode_DeepSeekを安全に使う.md) を参照してください。

## 4. Antigravity CLI（agy）

Google の Gemini CLI の後継です。**新規受講者にはこちらを推奨**します（公式の継続サポート対象）。
Antigravity CLI は Go バイナリで、**Node.js は不要**です。

### Windows

PowerShell で以下を実行（出典：本パッケージの `launch-agy-safe.ps1` 記載のインストール手順）：

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

インストール後、`agy` が見つからない場合は、次の手順で対処してください：

**1. まず実際のインストール先を確認する**（端末・バージョンで配置先が異なる場合があります）：

```powershell
Get-Command agy        # 見つかればフルパスが表示されます
where.exe agy          # 上で出ない場合はこちらも試す
```

**2. 確実な回避策 — 環境変数 `AGY` にそのフルパスをセットする**
（本パッケージの `launch-agy-safe.ps1` は `AGY` を最優先で参照するため、これが最も確実です）：

```powershell
setx AGY "C:\実際に確認したフルパス\agy.exe"
```

> 正確なインストール先は端末・バージョンにより異なる場合があります。
> なお `%LOCALAPPDATA%\Antigravity\` は、本パッケージの launcher が探す既定候補の一つです（参考。ここに入るとは限りません）。

### Mac

ターミナルで以下を実行（出典：本パッケージの `launch-agy-safe.sh` 記載のインストール手順）：

```bash
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

インストール後、`agy` が見つからない場合は、次のどちらかを満たしてください：

- `$HOME/.local/bin` が PATH に含まれている（agy は `~/.local/bin/agy` に入ります）
- 環境変数 `AGY` に agy バイナリのフルパスをセット

> **agy は起動後に手動設定が必要**：agy は user-level の設定ファイルしか持たないため、launcher だけでは防御を強制しきれません。agy 起動後に `/settings` を開いて `configs/agy/recommended-settings.json` の値に合わせ、**Secure Mode を ON** にしてください。詳細は [99_known_issues.md](99_known_issues.md)。

> **agy の更新について**：agy は公式の自動更新のしくみを持っています。「8_AIツールを最新版に更新」ボタンの対象外ですが、ふだんは公式の自動更新に任せておけば大丈夫です。入れ直したいときだけ、上の公式インストールコマンドをもう一度実行してください。

→ 起動は `launch-agy-safe` 経由で（[下記](#インストール後の起動方法必ずこれで起動)）。

## インストール後の起動方法（必ずこれで起動）

CLI を入れたら、起動は**必ず以下の safe launcher 経由**で行ってください。
素のコマンド（`codex` / `claude` / `opencode` / `gemini` / `agy`）を直接打つと、このパッケージの保護は効きません。

まず workspace フォルダに移動してから、使いたい AI の launcher を実行します。

### Windows

```powershell
cd $env:USERPROFILE\Documents\my-ai-workspace

# Codex CLI
powershell -File .ai-safety\hooks\windows\launch-codex-safe.ps1

# Claude Code
powershell -File .ai-safety\hooks\windows\launch-claude-safe.ps1

# Gemini CLI（廃止済み・過去に入れた人のみ）
powershell -File .ai-safety\hooks\windows\launch-gemini-safe.ps1

# Antigravity CLI（agy）
powershell -File .ai-safety\hooks\windows\launch-agy-safe.ps1

# OpenCode + DeepSeek
powershell -File .ai-safety\hooks\windows\launch-integrated.ps1 -Workspace . -Agent opencode -Profile standard
```

### Mac

```bash
cd ~/Documents/my-ai-workspace

# Codex CLI
bash .ai-safety/hooks/macos/launch-codex-safe.sh

# Claude Code
bash .ai-safety/hooks/macos/launch-claude-safe.sh

# Gemini CLI（廃止済み・過去に入れた人のみ）
bash .ai-safety/hooks/macos/launch-gemini-safe.sh

# Antigravity CLI（agy）
bash .ai-safety/hooks/macos/launch-agy-safe.sh

# OpenCode + DeepSeek
bash .ai-safety/hooks/macos/launch-integrated.sh "$(pwd)" opencode standard
```
