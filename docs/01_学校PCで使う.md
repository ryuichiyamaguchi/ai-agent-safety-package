# 学校 PC（Windows）で使う

職業訓練校の演習用 PC で AI エージェント安全運用パッケージ v1.0.7 を使う手順です。

## 前提

- Windows 10 / 11
- 「user」アカウント（管理者権限なし）
- Cursor が既にインストール済み
- Codex CLI（`codex --version` が動く状態）が既にインストール済み

## ステップ 0：最初の儀式（5分・必須）

Cursor のターミナルを開いて、以下の 1 行を実行してください。

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

確認プロンプトで `Y` を押す → 完了。

**なぜ必要か**：Windows の標準設定では PowerShell スクリプトの実行が止められており、このままだと `npm` 系コマンドや一部の `.ps1` スクリプトが動きません（Day1 でこれが原因で多くの人が詰まりました）。この 1 行で「自分のユーザーの範囲だけ、署名付きスクリプトを許可する」設定に変えます（システム全体には影響しません）。

**一度実行すれば永続的に有効**です。

## ステップ 1：パッケージのダウンロード

講師から配布された URL または QR コードから ZIP ファイルをダウンロードします。

ダウンロード先：**デスクトップ**（パスが短くて安全）

ファイル名：`ai-agent-safety-package-v1.zip`（中身は v1.0.7）

## ステップ 2：展開

ZIP ファイルを右クリック →「すべて展開」→ 展開先はそのまま（デスクトップ）→「展開」。

展開後、デスクトップに `ai-agent-safety-package-v1` フォルダができます。

## ステップ 3：インストール

Cursor を起動し、`File` → `Open Folder` で `ai-agent-safety-package-v1` フォルダを開きます。

Cursor の中で `Terminal` → `New Terminal` を選びます（メニューになければ `Ctrl + \``）。

開いたターミナルに以下の 1 行をコピペして Enter：

```
powershell -ExecutionPolicy Bypass -File scripts\windows\install.ps1 -Workspace "$env:USERPROFILE\Desktop\my-project"
```

`my-project` は自由に変えて構いません（自分の作業フォルダにしたい名前にする）。

実行すると `Desktop\my-project` フォルダが作られ、その中に安全装置が組み込まれます。

## ステップ 4：動作確認（doctor）

以下の 1 行で、攻撃ドリルが実際に止まることを確認します。

```
powershell -ExecutionPolicy Bypass -File "$env:USERPROFILE\Desktop\my-project\.ai-safety\hooks\windows\doctor.ps1"
```

`pass=10 fail=0` が出れば成功です。1 つでも fail が出たら、講師に連絡してください。

## ステップ 5：使う

Cursor で `Desktop\my-project` フォルダを開きます。

ターミナルから以下のコマンドで安全な Codex CLI を起動：

```
powershell -ExecutionPolicy Bypass -File .ai-safety\hooks\windows\launch-codex-safe.ps1
```

これで Codex CLI が**対話モード（TUI）**で起動します。

v1.0.7 では、この launcher 経由で起動した Codex は以下の状態になります。

- `--sandbox workspace-write`：workspace 外への書き込みは OS が拒否
- `network_access = false`：curl / wget / 外部送信は全ブロック
- `--ask-for-approval untrusted`：`cat` / `ls` / `sed` 等の安全コマンド以外は、実行前に**承認ダイアログ**が出る

`.env` を表示するだけのような無害な閲覧は通りますが、`python` でファイルを読み出すスクリプト、`curl`、`rm -rf` などは**承認ダイアログで止まる**ので、そこで「いいえ」を押せば実行されません。

> 注意：launcher を使わずに `codex exec ...` のように非対話で叩くと、承認ポリシーは強制的に `never` に降格されます。**必ず上記の launcher 経由で起動してください**。

## 毎日の使い方

朝、Cursor で `Desktop\my-project` を開く → ターミナルで上の launch コマンドを叩く → 1 日中安全に作業する → 終わったら Cursor を閉じる。

## バックアップ / リストア

```
powershell -ExecutionPolicy Bypass -File .ai-safety\hooks\windows\backup.ps1
powershell -ExecutionPolicy Bypass -File .ai-safety\hooks\windows\restore.ps1
```
