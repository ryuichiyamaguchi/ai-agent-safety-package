はじめての人だけ・最初の1回だけ

下ごしらえ（AIを動かす準備）

パソコンに「AIを動かすための道具」を入れます。1回やれば、次からは飛ばしてOKです。

0-1　Node.js（ノードジェイエス）を入れる

なぜAIツールを動かすための「土台」です。これが無いとAIが動きません。
何が起きる下のリンクから公式サイトを開き、LTS版（おすすめ・安定版）をダウンロードしてインストールします。

Node.js 公式サイトを開く（LTS版を選ぶ）

入れ終わったら、ちゃんと入ったか確認（黒い画面に貼って Enter）

$node -v
$npm -v

v20.◯◯ のように数字が出れば成功です（数字はバージョンなので何でもOK）。

0-2　AIのCLI（コマンド）を入れる

なぜ使いたいAIの「本体」です。使うものだけ入れればOK（全部入れても構いません）。
何が起きる黒い画面（PowerShellターミナル）に貼って Enter すると、自動でダウンロード＆セットアップされます。
どれを入れる？　あなたの課金状況で決めてください。
・無課金 → OpenCode（無料モデルを自分で選ぶ）か AntiGravity（どちらも無料）。Codex のデスクトップアプリは無料プランでも使えます。Claude のような使い心地が欲しいなら OpenCode + DeepSeek（少額チャージ・送信検査つき）も
・ChatGPT に課金している → Codex（CLI がどのプランで使えるかは変わるので公式で確認してください）
・Claude に課金している → Claude Code（無料プランでは使えません）
くわしい表は docs フォルダの 00_はじめに と 20_卒業後ガイド にあります。

Codex（コーデックス）を使う人

$npm install -g @openai/codex

Claude Code（クロードコード）を使う人

$npm install -g @anthropic-ai/claude-code@latest

OpenCode（オープンコード）+ DeepSeek を使う人

$npm install -g opencode-ai

AntiGravity（アンチグラビティ）を使う人

$irm https://antigravity.google/cli/install.ps1 | iex
$curl -fsSL https://antigravity.google/cli/install.sh | bash

これはネットから取得して実行するコマンドです。表示元が公式（antigravity.google）であることを確かめてから実行してください。

AntiGravity 公式ページを開く

0-3　ログインする

なぜあなたのAIアカウントと結びつけるためです。
何が起きる下を貼って Enter すると、ログイン画面（またはAPIキーの入力）が始まります。
$codex login
APIキーの入力だけは、あなた自身でやる必要があります。　キー（パスワードのようなもの）はとても大切な情報です。人に見せたり、チャットに貼ったりしないでください。

0-4　PowerShell の実行許可（Windowsのみ・1回だけ）

Windows 専用
なぜWindowsは初期状態だと、安全のため一部のスクリプトを止めます。安全パッケージのファイルを動かせるように、1回だけ許可します。
何が起きるこのパソコンの「あなたのアカウントだけ」で、署名済みスクリプトを動かせるようになります。

PowerShell を「ふつうに」（管理者でなくてOK）開いて、1回だけ貼る

PS>Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

途中で「変更しますか？」と聞かれたら Y を入れて Enter。

0-4　初回の安全許可（Macのみ・1回だけ）

Mac 専用
なぜMacは「ネットから来たファイル」を最初はブロックします。安全パッケージを動かすために、1回だけ許可します。
何が起きる「開いてもいいよ」とMacに伝わり、次回からふつうに開けるようになります。

おすすめ：画面の案内から許可する（コマンド不要）

システム設定 › プライバシーとセキュリティ › 「このまま開く」を押す

うまく出ないときの代わりのコマンド（解凍したフォルダの中で実行）

$xattr -dr com.apple.quarantine .

※ 末尾の「.（ドット）」は「いまのフォルダ全部」という意味です。必ず解凍したフォルダの中で実行してください。

▸ うまくいかない時（クリックで開く）
  • node -v で何も出ない／エラー：0-1 のインストールがまだか、パソコンの再起動で直ることがあります。
  • npm install が赤い文字で止まる：ネット接続を確認し、もう一度同じコマンドを貼ってみてください。
  • Windows：「このスクリプトは実行できません」：0-4 の実行許可をまだやっていません。先に 0-4 を済ませてください。
  • Mac：「開発元を確認できません」：0-4 の安全許可をまだやっていません。先に 0-4 を済ませてください。

いちばん最初のひと押し

安全パッケージを準備する

Windows：1_安全パッケージを準備-Windows.bat をダブルクリックします。
.bat の中身を PowerShell に貼らないでください。　@echo off や %~dp0 は PowerShell では動きません。セキュリティで .bat が止められた時だけ、下の代替手順を使います。

.bat が止められた時だけ：この「スタート.html」があるフォルダで PowerShell を開いて貼る

PS>if (Test-Path ".\scripts\windows\install.ps1") { Get-ChildItem -LiteralPath . -Recurse -ErrorAction SilentlyContinue | Unblock-File -ErrorAction SilentlyContinue; powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\windows\install.ps1" -Workspace "$env:USERPROFILE\Documents\my-ai-workspace" } else { Write-Host "スタート.html があるフォルダで PowerShell を開き直してください" }
Mac：1_安全パッケージを準備-Mac.command を右クリック → 「開く」→ もう一度「開く」を押します。
なぜAIが安全に動くための「作業部屋」と「安全設定」を、自動で用意します。
何が起きるあなたの書類ドキュメントフォルダの中に my-ai-workspace ができ、安全設定が入り、自己診断（doctor）が自動で走ります。最後に「準備OK」と出れば成功です。準備が終わると、次に使う「スタート」フォルダが自動で開きます。
▸ うまくいかない時（クリックで開く）
  • Windows：黒い画面が一瞬で消える／「実行できません」→ Step 0-4（PowerShellの実行許可）を先に済ませてください。それでも .bat が止められる場合は、上の PowerShell 代替コマンドを使ってください。
  • Mac：「開けません」と言われる→ Step 0-4（初回の安全許可）を先に済ませてください。ダブルクリックではなく右クリック→開くが大切です。
  • 途中で止まったように見えても、文字が流れている間は動いています。終わるまで待ちましょう。

いよいよAIを動かす

AIエージェントを安全に起動する

Step 1 が終わると、この「スタート」フォルダは自動で開きます。
開いたフォルダの中の、使いたいAIのファイルをダブルクリックしてください。

手動で開きたいときは、このフォルダの場所をコピーして使えます

📂%USERPROFILE%\Documents\my-ai-workspace\スタート

エクスプローラーのアドレス欄に貼って Enter で開けます。

📂~/Documents/my-ai-workspace/スタート

Finder で Command+Shift+G を押し、貼って Enter で開けます。

  1. 4_AIを起動する.bat.command … ふだんはこれ 1 つ。AIと見守り画面を一緒に起動します。開いたメニューから OpenCode 無料モデル（完全無課金の人）／AntiGravity（無料）／OpenCode + DeepSeek（少額チャージ・送信検査つき）／Codex（ChatGPT 課金の人）／Claude（Claude 課金の人）を選びます
  2. 3_じぶんに合うAIを選ぶ.bat.command … どれを選べばいいか迷ったら、先にこれを押してください。課金状況別の選び方ガイドがブラウザで開きます
  3. 5_Codexデスクトップアプリを起動.bat.command … Codex をアプリで使う人はこちら（無料プランでも使えます。入っていなければ公式サイトを案内します）

AGI Cockpit（1 つのアプリで AI を使い分けるアプリ）で Claude を使いたい人は、docs フォルダの 11_AGI-Cockpitで使う を読んでください（作業フォルダを my-ai-workspace にすれば保護が効きます。Codex だけは上の 4_AIを起動する から）。

慣れてきたら：キーと金庫/12_PC全体に安全設定を入れる.bat.command … Claude Code・Codex・AntiGravity・OpenCode をどのフォルダから起動しても危険コマンド（再帰削除・.env の読み取り・外部への送信など）を止めます。Codex はデスクトップアプリも同じ設定ファイルを読むので、アプリ側にも同時に効きます。元に戻したいときは キーと金庫/13_PC全体の安全設定を解除.bat.command を実行してください（適用前のバックアップから元の設定に戻します）。

案件ごとに作業を分けたいときは、my-ai-workspace の中にサブフォルダを作ってください。作業フォルダの安全ルールと見張りが、その中でもそのまま効きます。

目を離して AI に長く作業させたいとき：6_長時間おまかせモードで起動.bat.command … 確認ダイアログをほとんど出さずに進めます。押すとメニューが出るので、Claude／Codex／OpenCode／AntiGravity から選んでください（Mac でも Windows でも使えます）。このモードは「全部素通し」ではありません。再帰削除・秘密ファイルの読み取り・sudo・git push などは止まったままで、記録もそのまま残ります。「壁」（OS が作業フォルダの外への書き込みを止める仕組み）がある組み合わせ（Mac の Claude／Mac と Windows の Codex）では、壁を立てられなかったときは起動しません。壁が無い組み合わせ（Windows の Claude／OpenCode／AntiGravity）では、起動前に「この環境には壁がありません」という確認が一度だけ出ます。「はい」と入力しないかぎり起動しません。この作業フォルダに大事なファイルを置かないでください。くわしくは docs フォルダの 20_卒業後ガイド へ。

合言葉やトークンを安全にしまいたいとき：キーと金庫/7_金庫に秘密をしまう.bat.command … 好きな名前を付けて、短い文字列をパソコンの金庫（Mac のキーチェーンWindows の DPAPI）に入れます。メモ帳のファイルと違って中身は暗号化され、この PC にログインできる本人だけが取り出せます。取り出すときは キーと金庫/8_金庫から秘密を取り出す.bat.command（画面には出さずクリップボードに入れて 60 秒後に自動で消します）、いらなくなったら キーと金庫/9_金庫の秘密を消す.bat.command です。入れられるのは短い文字列だけです（英数字なら約 90 文字、日本語なら約 30 文字まで）。

守られ方は、AI ツールごとに違います。　Codex は Mac でも Windows でも「壁」（パソコン本体が力ずくで止める仕組み）が効きます。Claude Code は Mac では壁が効きますが、Windows では壁が使えません（Claude Code 自体が未対応のため）。OpenCode には壁がありません（作った人たち自身が「これは隔離ではない」と公式に書いています）。そしてどの壁も「読み取り」は止めません。秘密のファイルを守っているのは .ai-safety フォルダの見張りなので、ここを消さないでください。くわしくは docs フォルダの 91_やさしい仕組み解説 へ。
なぜ「安全モード」で起動することで、危険な操作にガードがかかった状態でAIを使えます。
何が起きる専用の画面が開き、AIに話しかけられるようになります。使いたい1つだけ起動すればOKです。
▸ うまくいかない時（クリックで開く）
  • 「コマンドが見つかりません」と出る：そのAIの本体がまだです→ Step 0-2 でインストールしてください。
  • ログインを求められる／認証エラー：Step 0-3 のログインがまだです。
  • スタート フォルダが無い：Step 1 の準備がまだか、失敗しています。Step 1 をやり直してください。

安心して見守る

見守りモニターを起動する

4_AIを起動するを使った場合は、見守り画面も自動で開きます。個別に開く時だけ別ウィンドウで 7_見守りモニターを起動 をダブルクリックします。
なぜ危険なコマンド実行・ファイル書き込み・ブロック理由を、横の画面で確認できると安心だからです。
何が起きるブラウザが開き、安全イベントとAI回答の画面が表示されます。最初は「待機中」です。危険操作や確認が必要な操作が出ると、自動で内容が切り替わります。AI回答は、取得できる環境でだけ表示されます。
🔑
AIコーチ（相談機能）を使うには、無料キーを一度だけ登録します。モニター画面に出る 「🔑 キーを登録／変更する」ボタン、または キーと金庫/3_AIコーチのキーを登録 をダブルクリックし、Google AI Studio（無料）で作ったキーを貼り付けるだけです。約1分・キーはこのパソコンの中だけに保存されます。登録しないと、コーチに聞いても答えません。

※ 見守りモニターは Codex / Claude / OpenCode の統合起動に対応します。AntiGravity は別のしくみ（OS隔離）で守るため、モニターには表示されません。

▸ うまくいかない時（クリックで開く）
  • ブラウザが開かない：もう一度ダブルクリックしてみてください。それでも開かない時は、表示されたファイルの場所をブラウザに手で入力しても見られます。
  • 「待機中」のまま変わらない：これは正常です。検索や会話だけでは表示が変わらないことがあります。危険操作・ファイル書き込み・ブロックなどの安全イベントが出ると切り替わります。AI回答は、取得できる環境でだけ表示されます。

上級・希望者だけ

DeepSeek（ディープシーク）を使う

これは使いたい人だけの追加機能です。よく分からない場合は、ここは飛ばして大丈夫です。ファイルはどれも Step 2 と同じ「スタート」フォルダの中にあります（フォルダの場所は Step 2 のパスからコピーできます）。

  1. ① キーと金庫/1_DeepSeekキーを登録（初回だけ）
    DeepSeek の APIキー（パスワードのようなもの）を貼って登録します。キーの作り方・チャージのやり方は docs フォルダの 20_卒業後ガイド にあります。
  2. ② 4_AIを起動する から「OpenCode + DeepSeek」を選ぶ
    これで、送信検査 Gateway が自動で立ち上がり、APIキーなどを送る前にマスキング（隠す）した状態で DeepSeek につながります。ふだんは「Web検索OFF」の方を選んでください。
  3. ③ キーと金庫/2_DeepSeekキーを削除
    使い終わって、やめる時に押します。登録したキーを消します。

必ず読んでください（正直なお知らせ）

会話の内容は DeepSeek（中国管轄のサーバー）に送信されます。マスキングは既知のパターンに限られ、すべてを隠せる完全な保証ではありません。本当に困る情報（個人情報・機密・パスワード等）は入力しないでください。

補足：Gateway は手動で起動する必要はありません（②が内部で自動的に立ち上げます）。マスキングした内容の元への復元はベストエフォート（できる範囲での対応）です。

▸ うまくいかない時（クリックで開く）
  • 「キーが登録されていません」：先に ① でキーを登録してください。
  • 接続できない／途中で止まる：いったん画面を閉じ、② をもう一度開き直してください。Gateway も一緒に立ち上がり直します。
  • 「残高不足（Insufficient Balance）」と出る：DeepSeek のチャージが切れています。docs フォルダの 20_卒業後ガイド の手順でチャージしてください。
  • キーを完全に消したい：③ を実行してください。登録したキーが削除されます。

卒業しても、ずっと使える

卒業後もずっと使う（更新の習慣）

講座が終わっても、安全装置とボタンはそのまま使えます。覚えることは「1 → 2 の順に押す」だけです。

  1. 1_安全パッケージを最新版にする … 安全装置とドキュメントを最新にします（先に押す）
  2. 2_AIツールをまとめて入れる … Codex／Claude Code／OpenCode の本体を、動作確認済みの版に更新します（後に押す。入れていないツールは自動でスキップ）
なぜAIツールは更新が速く、古いままだと安全装置と噛み合わなくなることがあるからです。月に1回くらい押すのがおすすめです。
何が起きる黒い画面が開いて、いまの版 → 新しい版が表示されます。困ったら 9_困ったとき診断 を押してください。
Windows診断や AI コーチのキー登録で「アクセスが拒否されました」と出たら、12_フォルダのアクセス権を直す を押してください。API キーの金庫フォルダの鍵が壊れているだけで、キーは無事です（作り直し不要）。手で直すときは コマンドプロンプト（cmd） を開いて icacls "%USERPROFILE%\.ai-safety" /reset /T /C /Q を貼り付けて実行します（PowerShell では %USERPROFILE% が展開されないため動きません）。コマンドが苦手なときは、%USERPROFILE% を開く → .ai-safety を右クリック → プロパティ → セキュリティ → 詳細設定 → 「継承の有効化」→「子オブジェクトのアクセス許可エントリすべてを…置き換える」にチェック → OK でも直せます。詳しくは 99_known_issues。
卒業後の全部のこと（アプリと CLI の選び方・費用・キーが使えなくなったときの対処・困ったときの調べ方）は、docs フォルダの 20_卒業後ガイド に 1 枚でまとまっています。　講座中に d-claude を使っていた人は、必ず一度読んでください。

卒業後の選び方（3 行）

  • 🖥️ 手軽に・安全に・実用優先 → デスクトップアプリ
  • ⌨️ 仕組みを学びながら深く使えるようになりたい → CLI（このパッケージのボタン）
  • 💰 無料で使いたい → Codex アプリ、または OpenCode + DeepSeek

アプリと CLI の違いは「できることの差」ではなく「守られ方の差」です。アプリでも自動化も定期実行もできます。違うのは、このパッケージの安全装置が効くかどうかです（20_卒業後ガイド の 4 章に全部書いてあります）。
