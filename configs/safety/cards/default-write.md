# この操作は何？

AI が新しいファイルを作成、または既存ファイルを上書きしようとしています。コード生成・設定変更・ドキュメント作成など用途は様々です。

# 承認前にチェック

- 書き込み先のパスは想定したプロジェクトの中か
- 既存ファイルの **上書き** ではないか（差分を確認できるか）
- 書き込み内容が想定と合っているか
- `.env` や `~/.ssh/` のような機密ファイルに書こうとしていないか

# 「許可しない」を選ぶべき

- パスがプロジェクト外に飛び出している
- 既存の大事なファイルを盲目的に上書きしようとしている
- 中身を読まずに承認するには大きすぎる差分

# パッケージの守りの状態

`guard-write` が `.env` / `.ssh` / 秘密情報パターンなどを判定し、危険なものは自動ブロックしています。それ以外は **あなたの判断** に委ねられます。
