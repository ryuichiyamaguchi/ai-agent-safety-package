# この操作は何？

`localhost` `127.0.0.1` `10.x.x.x` `192.168.x.x` などは、**自分の PC や家庭内/社内ネットワーク** を指します。AI が外部の Web を取りに行く想定の `WebFetch` で、これらが指定されているのは通常はおかしい挙動です。

# 承認前にチェック

- なぜローカル/内部アドレスにアクセスするのか
- ローカルで起動中のサービスから何かを取り出そうとしていないか
- 内部ネットワークの別マシンを探索しようとしていないか（SSRF 攻撃の典型パターン）

# 「許可しない」を選ぶべき

- 自分でローカルサーバーを動かしてその確認をしている等、明確な意図がない場合は **原則ブロック**
- AI が「環境チェックのために」とだけ言って詳細がない

# パッケージの守りの状態

このパターンは `guard-webfetch` で **常にブロック** されます。解説カードが出ているということは、ブロックされた直前の様子を確認できる状態です。
