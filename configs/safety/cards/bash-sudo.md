# このコマンドは何？

`sudo` は **管理者（root）権限** でコマンドを実行する命令。OS の設定変更、システムファイルの書き換え、他ユーザーのファイル削除など、通常権限ではできない操作が一気に可能になります。

# 承認前にチェック

- なぜ管理者権限が必要なのか、AI が説明しているか
- システム全体に影響する操作か（例: `/etc/` の書き換え）
- 一般ユーザー権限でも同じことができないか
- 一度許可すると **そのセッション中はパスワードなしで sudo が通る** ことを意識する

# 「許可しない」を選ぶべき

- AI が「念のため sudo つけときます」と言うだけで必然性が薄い
- ユーザー領域（`~/` 内）で完結する作業のはず
- Homebrew や npm のインストールなど、本来 sudo 不要の操作に sudo がついている

# パッケージの守りの状態

`sudo` 単体ではブロックされません（用途が広いため）。**ユーザー判断** が前提です。学校 PC など共有環境では特に慎重に。
