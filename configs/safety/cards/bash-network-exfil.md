# このコマンドは何？

`curl` `wget` `nc` `Invoke-WebRequest` などは **インターネットや他のマシンと通信** するコマンド。便利な反面、ローカルの情報を外に送り出す（exfiltration）経路にもなり得ます。

# 承認前にチェック

- 通信先の URL/ホストは何か
- ローカルのファイルを **アップロード** しているのではないか（`curl -F` `curl -d @file` `--upload-file`）
- 単にダウンロードしているだけか
- API キーや認証情報を一緒に送っていないか（クエリ文字列に含まれていないか）

# 「許可しない」を選ぶべき

- ローカルファイルを外部に送る挙動なのに、AI の説明にその記述がない
- 送り先ホストが見覚えのないドメイン
- リクエストヘッダに認証情報が含まれていて、その出どころが不明

# パッケージの守りの状態

`WebFetch` 経由のアクセスは **許可ドメインリスト** で守られていますが、`Bash` 内の `curl/wget` 自体はブロックされません。ユーザー判断が要ります。
