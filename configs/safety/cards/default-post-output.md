# この操作は何？

AI またはツールが出力したテキストを、ガードが事後チェックしている状態です。秘密情報パターンが画面に出てしまわないかをチェックします。

# このタイミングで意識したいこと

- AI が出した内容に、自分が過去に貼ったキーが映り込んでいないか
- ファイル一覧の中に `.env` などのパスが見えていないか（漏れの可能性）

# パッケージの守りの状態

`guard-post-output` が出力テキスト中の秘密情報パターンをチェックし、検出すれば **自動ブロック** します。同時に、監査ログに書く前に redact 処理がかかるため、ログ自体は安全です。
