# 何が起きている？

ユーザー入力／AI 出力に **API キーやトークンの形式** に一致する文字列が含まれています:

- OpenAI / Anthropic / Google AI のキー
- AWS アクセスキー
- GitHub Personal Access Token
- Slack トークン

これがそのままログや画面に出てしまうと、**漏洩** の入り口になります。

# 承認前にチェック

- 自分で本物のキーを貼り付けてしまっていないか
- AI の出力に、これまで自分が貼ったキーが映り込んでいないか
- このセッションのログがどこに残るか（このパッケージは自動で redact します）

# 「許可しない」を選ぶべき

- このパターンに該当する場合は、**ガード側で自動ブロック** されます
- ブロック後はキーをローテートする（漏洩した前提で扱う）のが安全

# パッケージの守りの状態

- 監査ログ (`~/.ai-safety/logs/events-YYYY-MM-DD.jsonl`) に書き込まれる際は、秘密情報パターンは自動的に `[REDACTED:...]` に置換されます
- 画面に出てしまったキーは、念のため再発行（ローテート）してください
