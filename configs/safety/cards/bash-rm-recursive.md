# このコマンドは何？

`rm -rf <パス>` は指定したフォルダとその中身を **すべて削除** する強力なコマンド。確認は出ず、ゴミ箱にも入らず、復元はほぼ不可能です。

# 承認前にチェック

- 削除対象のパスは意図通りか（タイポしていないか）
- `/` や `~/` や `*` が誤って入っていないか
- 自分が `cd` している場所と整合しているか
- 大事なファイル（書きかけのコード、写真など）がそこに含まれていないか

# 「許可しない」を選ぶべき

- 削除対象のパスに心当たりがない
- AI が「念のため掃除します」と言うだけで、なぜ消すかの説明が薄い
- バックアップを取っていない

# パッケージの守りの状態

`.env` `~/.ssh/` など保護パスを巻き込む `rm -rf` は **自動でブロック** されます。そうでない一般のパスは「自己責任」での承認になります。
