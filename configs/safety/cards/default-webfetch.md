# この操作は何？

AI が `WebFetch` ツールで指定 URL を取得しようとしています。公式ドキュメントの参照、最新情報の取得などに使われます。

# 承認前にチェック

- アクセス先のドメインは何か（許可リスト内か）
- 何を取りに行くのか説明があるか
- 取得した内容を AI がそのまま実行しようとしていないか

# 「許可しない」を選ぶべき

- アクセス先のドメインに見覚えがない
- なぜこの URL を取るのか説明が薄い

# パッケージの守りの状態

`guard-webfetch` が **許可ドメインリスト** で守っています。リスト外・プライベートネットワーク・ブロック対象ドメインは **自動ブロック**。許可リスト内のドメインだけがここまで来ます。
