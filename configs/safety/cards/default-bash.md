# この操作は何？

AI がターミナル/シェル（bash / zsh / PowerShell）にコマンドを送り、実行しようとしています。これは AI が **「外の世界」に手を伸ばす** 一番強力な手段です。

# 承認前にチェック

- コマンドの内容を **自分の目で読んで** 理解できるか
- どのディレクトリで実行されるか（`cwd` が想定通りか）
- ファイル・ネットワーク・システム設定のうち、何を触るか
- 同じことを自分で手動でやる場合と比べて、不自然な挙動が混ざっていないか

# 「許可しない」を選ぶべき

- コマンドの意味が読み取れない
- 「とりあえず実行してみる」状態
- 業務 PC / 学校 PC でリスクを取りたくないケース

# パッケージの守りの状態

`guard-bash` が `rm -rf` / `sudo` / 秘密情報パターンなどを判定し、危険なものは自動ブロックしています。それ以外は **あなたの判断** に委ねられます。
