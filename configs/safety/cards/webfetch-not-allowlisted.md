# この操作は何？

このパッケージの `WebFetch` ガードは **アクセス可能なドメインを限定** しています（公式ドキュメント・GitHub・npm registry など）。それ以外、特に `gist.github.com` `pastebin.com` `*.pages.dev` `transfer.sh` などの **匿名公開ストレージ** はブロック対象です。

# 承認前にチェック

- なぜそのドメインにアクセスする必要があるのか
- 同じ情報を公式ドキュメントから取れないか
- 匿名ストレージ系のホストは、攻撃者が悪意あるコンテンツを置く定番場所であることを意識する

# 「許可しない」を選ぶべき

- アクセス先が gist / pastebin / transfer.sh 系の場合は **原則ブロック**
- 出典が分からない短縮 URL や見覚えのないドメイン

# パッケージの守りの状態

このカテゴリは `guard-webfetch` で **常にブロック** されます。受講者は「ブロックされた理由」を確認するためにこのカードを読んでください。
