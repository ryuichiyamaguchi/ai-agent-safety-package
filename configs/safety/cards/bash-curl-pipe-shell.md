# このコマンドは何？

`curl ... | bash` は **インターネットから取ってきた中身を、見ずにそのまま実行** する書き方。中身が安全か検証する隙がありません。改ざんされていても気付けません。

# 承認前にチェック

- ダウンロード元の URL は公式か（タイポドメインの罠もある）
- 自分が知っているソフトのインストール手順か
- 「公式 README に書いてある通り」のコマンドか
- 一旦 `curl -O` でファイルに保存して、中身を読んでから実行する選択肢はないか

# 「許可しない」を選ぶべき

- URL に見覚えがない、または短縮 URL になっている
- AI が「ちょっと便利なスクリプトです」と言うだけで出典が曖昧
- 公式手順で「ファイル保存 → 中身確認 → 実行」を案内している場合（通常はこちらが推奨）

# パッケージの守りの状態

このパターンは特に危険なので、`bash` 承認時にこの解説が **必ず** 出るようになっています。判断はあなたに委ねられます。
