# この操作は何？

ユーザーが入力したプロンプト（AI への指示）を、ガードが事前チェックしている状態です。秘密情報や危険なコマンドパターンが含まれていないかをチェックします。

# このタイミングで意識したいこと

- 自分の入力に **API キー** や **パスワード** を **直接** 貼っていないか
- 他人の個人情報を入れていないか
- AI に渡る前に止めたい情報が無いか

# パッケージの守りの状態

`guard-prompt` がプロンプト送信前に秘密情報パターンをチェックし、検出すれば **自動ブロック** します。検出されなかった場合はそのまま AI に渡されます。
