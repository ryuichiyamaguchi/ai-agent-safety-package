# この操作は何？

`~/.ssh/` `id_rsa` `~/.aws/` `~/.gnupg/` `~/.kube/` `.npmrc` `.pypirc` は **認証情報の保管場所**。鍵・トークン・認証クッキーが入っており、書き換えると他のソフト（git push, aws cli, kubectl など）が動かなくなったり、逆に **乗っ取り** に使われたりします。

# 承認前にチェック

- なぜここに書き込む必要があるのか、AI が説明しているか
- 既存ファイルの上書きか、新規追記か
- 書き込み内容が承認画面に表示されているか
- 本来このファイルを編集するのは別の正規ツール（`ssh-keygen` `aws configure` など）ではないか

# 「許可しない」を選ぶべき

- AI が「初期化のために書き換えます」とだけ言って具体的な理由がない
- 内容に他人の公開鍵らしきものが含まれている（侵入の足がかりに使われる典型パターン）
- 本来の用途と関係ない作業の途中で出てきた

# パッケージの守りの状態

このパターンは `guard-write` で **基本ブロック** されます。プロンプトが出る場合は何かしらの抜け道を通っているので、原則「許可しない」が安全側です。
